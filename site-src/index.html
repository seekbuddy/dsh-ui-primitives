为 DeepSeek Harness 插件打造的 UI 组件库

dsh-ui-kit 忠实复刻 DeepSeek Harness Web UI 的设计系统与 UI 原子组件。 --dsw-* tokens、明暗主题、组件样式与官方 @deepseek-ai/dsh-client-ui-primitives / dsh-client-ui-theme 严格一致，让第三方插件与宿主界面无缝融合。

快速开始 在 GitHub 上查看
npm i dsh-ui-kit

为什么选择 dsh-ui-kit？

🎨

完整设计 Token

覆盖 --dsw-static-* 色板、语义别名、产品专属 token、阴影、字体与 Shiki 高亮调色板，明暗两套自动成立。

🌗

明暗主题同源

通过 body[data-ds-dark-theme] 属性切换，与 DeepSeek Harness 宿主完全同机制，插件无需二次适配。

🧩

零 Cordis 依赖

纯 props 原子组件，可在任何 React 18 / 19 应用中使用，没有运行时框架绑定。

📦

自包含样式

组件样式在构建时编译为 hash 类名并在运行时自动注入，无需任何 CSS Modules 配置。

🔤

数学与代码

KaTeX woff2 字体按需发布，Shiki 语法高亮，MarkdownText 支持 GFM、数学与流式增量解析。

📐

类型完整

全套 TypeScript 声明，构建产物包含可发布 ESM bundle 与精确类型。

快速开始

按职责从独立入口导入；tokens.css 与 katex.css 由应用全局加载一次。

import { Button, Pill } from 'dsh-ui-kit'
import { MarkdownText } from 'dsh-ui-kit/markdown'
import { setThemePreference } from 'dsh-ui-kit/theme'
import 'dsh-ui-kit/tokens.css'
import 'dsh-ui-kit/katex.css'

const labels = { code: { copyLabel: '复制', copiedLabel: '已复制' }, footnotes: '脚注' }

export function MyPluginUI() {
  return (
    <div style={{ fontFamily: 'var(--dsw-font-family)' }}>
      <Button variant="primary" onClick={() => setThemePreference('dark')}>切换深色</Button>
      <Pill active>激活</Pill>
      <MarkdownText text={'# 你好\n\n这是 **Markdown**'} labels={labels} />
    </div>
  )
}
